Typical workflow

  1. Merchant installs the app through Salla.
  2. Salla sends a signed authorization event.
  3. The store appears in the secure multi-store manager.
  4. Approved Merchant API actions can be read or updated.

No merchant password is required. Access can be revoked by uninstalling the app.
