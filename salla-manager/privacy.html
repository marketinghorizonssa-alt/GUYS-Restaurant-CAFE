Privacy Policy

We process only the Salla store data required to provide the management service after the merchant explicitly authorizes the app through Salla OAuth.

Data handled

Store identifiers, authorization tokens, and API data requested by authorized tools such as products, orders, customers, categories and settings.

Security

Authorization tokens are stored server-side and are never exposed through app tools. Webhook requests are verified using Salla signatures.

Retention and revocation

When a merchant uninstalls the app, API access is disabled and active credentials are removed from use.
